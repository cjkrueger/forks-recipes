# My recipes

Recipes in this repository are plain markdown files that
[Forks](https://useforks.com) reads and writes. Keep the repository available
wherever you want your recipes — no database, no account with anyone.

## Layout

```
recipes/
  {recipe-slug}/
    recipe.md              the recipe: YAML frontmatter + markdown body
    photo.jpg              optional image
    forks/                 optional forks of the recipe
.forks/                    app bookkeeping (collections, grocery list, meal plan)
  version
```
